# Colección incluida del Libro de Darwin

Estas 29 especies y sus ilustraciones se generaron durante el desarrollo del juego y se incluyen con autorización de su creador para jugar sin clave ni saldo de IA. Se reutilizaron las imágenes existentes, sin nuevas solicitudes a proveedores.

Cada ilustración se preparó con el mismo recorte del juego: PNG transparente de 192 × 192 para el mapa y 384 × 384 para el libro y la ficha. Los originales grandes y la caché privada no forman parte del repositorio.

`darwin-data.js` contiene exclusivamente los nombres, descripciones, rasgos y rutas de estos archivos. La colección personal de cada jugador se conserva en su navegador y se puede exportar/importar desde el libro; no se publica automáticamente en GitHub.
